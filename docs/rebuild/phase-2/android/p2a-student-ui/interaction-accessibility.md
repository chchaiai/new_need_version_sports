# P2A Android 交互与无障碍约定

## 1. 跨端一致与 Android 适配

必须与 Web 一致：

- 业务含义、状态语义、关键术语；
- 页面信息分组和任务顺序；
- 实际/有效/计入分钟的数据口径；
- 学生、教师、管理员的权限边界；
- 邀请、审核、一次补充、游泳和维护流程；
- 禁止向学生披露分数、等级、排名和内部信息。

允许按 Android 适配：

- Material/Compose 组件、卡片间距和响应式布局；
- 系统返回手势、顶部返回和模态关闭；
- 底部导航在小屏、横屏和系统栏下的安全区域；
- 相机、图库、麦克风和系统设置跳转；
- 键盘、输入法、系统字体缩放、深色主题和 TalkBack；
- Android 矢量图标的线宽和构图。

不要求像素级一致，但平台适配不得更改业务结果或省略异常状态。

## 2. 导航与返回规则

| 场景 | 返回行为 |
|---|---|
| 五个主标签 | 系统返回先回到首页；首页再次返回按 Android 常规退出/后台行为 |
| 普通二级页 | 返回来源页，并保留安全的筛选或滚动位置 |
| 扫码页 | 返回立即释放相机；再次进入重新核对权限和邀请状态 |
| 入班确认 | 返回预览/输入，不提交；提交中不得因重复返回制造第二请求 |
| 运动进行中 | 返回前提示会话仍在进行，可留在页面或按允许行为暂停；不得本地判完成 |
| 证据采集 | 返回保留本地草稿并说明尚未提交；涉及敏感媒体时不在通知/最近任务中暴露 |
| 锁定上传 | 返回不丢弃已受理批次；再次进入 PAGE-STU-042 恢复同一批次 |
| 一次补充 | 返回保留同一补充版本；不得通过重新进入创建第二机会 |
| 维护页 | 返回不能绕过维护进入业务页面 |

危险或不可逆动作使用明确确认，不把主操作放在容易误触的系统返回路径上。

## 3. 相机、麦克风与文件权限

- 仅在学生主动进入扫码、拍照或录像时请求相关权限。
- 先用页面内简短说明解释用途，再触发系统权限框。
- 首次拒绝：保留手动邀请码或已有材料查看等安全替代入口。
- 永久拒绝：提供“前往系统设置”，但不循环弹框或阻断无关页面。
- 录像需要麦克风是因为 MP4 必须含音轨；未获授权时不得显示录像成功。
- 不请求位置权限，不绘制路线或地图，也不从图片元数据衍生位置展示。
- 图片选择必须验证格式、数量和大小；UI 提示不能与运动证据、免测/认证两套上限混淆。

## 4. TalkBack 与可操作控件

- 所有可点击目标最小触控区域 48 × 48 dp。
- 图标按钮必须有可本地化的内容描述；纯装饰图标从语义树隐藏。
- 运动图标由父卡片读出“运动名称 + 选中状态”，避免图标名称重复播报。
- 卡片不能只靠颜色表达有效、无效、待处理或未计入；同时提供文字和必要图标。
- 分段控件、底部标签、筛选 Chip 和媒体槽位要暴露角色、当前值、选中与禁用状态。
- 加载、提交、上传完成、错误和维护切换使用适度的状态播报；进度变化不高频轰炸 TalkBack。
- 错误文本与对应输入关联，焦点移到第一个需要修正的位置。
- 倒计时读出准确截止信息；不每秒播报，临近截止采用有限提醒。

## 5. 字体、对比度与布局

- 支持系统字体放大；关键按钮、截止时间和状态不得截断或重叠。
- 主要文本和背景至少满足 WCAG AA 可读对比；禁用状态仍需可辨认。
- 横屏、小屏和大字体下，底部按钮不得遮住媒体槽位或最后一条说明。
- 长课程名、教师名、邮箱和错误消息允许换行；不通过缩小到不可读字号解决。
- 深色主题下保持状态语义一致，不能复用仅适用于浅色背景的警示色。
- 动效遵守系统“移除动画/减少动态效果”；业务完成不能只靠动画反馈。

## 6. 表单与错误反馈

- 标签不能只放在 placeholder 中；输入后仍能识别字段含义。
- 邮箱、邀请码、反馈、延迟说明等在旋转或进程恢复后保留安全草稿。
- 不在错误消息、分析日志或截图中回显 Token、验证码、签名 URL、真实学生资料或内部异常堆栈。
- 技术错误与业务拒绝分开：网络失败不显示“邀请已过期”，AI/上传失败不显示“记录无效”。
- 重试入口说明将重试哪一步，并避免重复入班、重复材料版本或重复提交。

## 7. 媒体与中断恢复

- 每个槽位显示材料版本、类型、预览状态、大小问题和是否已锁定。
- 已锁定批次不可通过 UI 删除后重新创建；允许的重试必须继续同一批次。
- 游泳前照、后照有独立且可读的槽位名称；总数量限制另行展示。
- 视频压缩、预览或上传失败保留原始草稿，不把失败项目显示为已上传。
- APP 进入后台、网络切换、屏幕旋转和进程重建均进入明确的 `RESUME` 表达。
- 恢复卡片需说明最后已知步骤、待继续内容和数据是否仅保存在本机。

## 8. 本地评审数据

- 所有本地样例统一显示“本地 UI 评审数据 / 无 Backend”。
- 使用虚构姓名、课程、邮箱、学号、时间和媒体缩略图。
- 不复用真实学生记录，也不把压缩包、日志或截图中的可能敏感内容复制进项目。
- 评审模式不得调用生产写接口；正式入口不得依靠样例数据才能显示。
- “点击查看下一状态”只能作为明确标识的评审控制，不能伪装真实扫码、入班、上传或审核成功。
