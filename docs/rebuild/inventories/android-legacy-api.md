## 结论摘要

- Android 没有 Retrofit 依赖、Retrofit Interface 或 Retrofit 注解；现存网络栈是手写 `OkHttp 4.12.0 + Gson 2.11.0 + V1ApiTransport`。
- Base URL 由 `BuildConfig.BNBU_API_BASE_URL` 注入，但客户端强制以 `/api/v1` 结尾；debug 默认值仍是 `http://10.0.2.2:13000/api/v1`。所有手写 `relativePath` 都属于待替换的旧 Contract 边界。
- `app/openapi/openapi.snapshot.yaml` 是 `3.0.0-contract` 的本地候选快照，`contract.properties` 标记为 `LOCAL_UNCOMMITTED_CANDIDATE`、133 个 operation；它不是新业务权威。快照仍明确声明“formal 60-minute session operation”，与当前业务文档“不增加 60 分钟”的规则冲突。
- 实际数据实现集中在 `ApiStudentRepository`、`V1StudentWorkspaceGateway`、`V1StudentApi` 和若干 V1 Gateway；没有名为 `RepositoryImpl` 或 `RemoteDataSource` 的独立层。`ApiStudentRepository` 实际兼任 Repository 实现、旧 DTO 兼容层和 API Adapter。
- 旧手写 DTO 仍有 9 个 Request 类、40 个 Response 类、18 处 `@SerializedName`；同时存在 OpenAPI 生成 DTO。两套 DTO 并存，并有 DTO/Transport 错误直接泄漏到 State、ViewModel/Controller 和 Compose UI。
- 静态调用图确认 55 个“实际或条件可达”的旧 HTTP method/path 目标（动态对象存储上传按 1 个目标计）；另有已声明但没有 `main` 调用者的旧 route。
- 未发现网络失败后伪造 Mock 成功的生产请求分支。发现的绕过集中在 debug 本地审查、未门禁的“模拟扫码成功”、本地时钟直达 2 小时，以及受测试能力门禁的旧“增加 60 分钟”。
- 四项原 `UNKNOWN` 已由用户决定并回填：模拟扫码成功不得进入正式产品；空 `MockStudentWorkspace.kt` 删除；运动记录 `resubmission` 不属于真实业务；版本策略辅助检查失败可以降级，但已缓存的强制升级要求不能被绕过。当前 Android 审计表没有待决定的 `UNKNOWN` 项。

“实际是否调用”的含义仅为 Android 当前源码的静态可达性：

- `是`：存在 `main` 调用链。
- `条件调用`：存在调用链，但受 build flag、环境、服务端 capability、页面状态或用户操作共同约束。
- `否`：仅声明、兼容壳或测试覆盖，未找到 `main` 调用者。

建议中的“替换”只表示保留已确认的 Use Case、等待新 Contract 后重建边界；本文不设计新 Endpoint。

## 旧状态枚举与旧错误码

### 状态枚举

当前真实边界依赖旧 generated enum，包括但不限于：

- 用户/选课/课程：`UserStatus`、`EnrollmentStatus`、`CourseStatus`、`Gender`、`CourseJoinGender`。
- 运动：`CreditType`、`ExerciseSessionStatus`、`ExerciseRecordStatus`、`ReviewResult`。
- 媒体：`MediaType`、`MediaUploadStatus` 及 request 内嵌枚举。
- 账号注销：手写 `AccountDeletionChallengeMode`。

这些值只说明旧客户端当前如何解析服务端，不构成新业务状态定义。尤其 `ReviewResult`、媒体状态和旧 `add-sixty-minutes` 相关 Session 状态必须随新 Contract 整体确认，不能逐项复制。

### 错误码

`V1ApiTransport` 会把服务端 code 与旧 generated `ErrorCode` 全量比对；新服务端若返回快照之外的合法错误码，旧客户端会将其降级为 protocol mismatch。UI/Controller 又直接针对下列旧 code 分支：

- 认证/邮箱：`AUTH_CREDENTIAL_INVALID`、`AUTH_SESSION_REVOKED`、`AUTH_ACCOUNT_DISABLED`、`AUTH_TOKEN_EXPIRED`、`AUTH_TOKEN_INVALID`、`CONTACT_BINDING_REQUIRED`、`AUTH_VERIFICATION_CODE_INVALID`、`AUTH_RATE_LIMITED`。
- 加课：`COURSE_INVITE_EXPIRED`、`COURSE_INVITE_REVOKED`、`COURSE_INVITE_INVALID`、`AUTH_JOIN_CAPABILITY_EXPIRED`、`AUTH_JOIN_CAPABILITY_INVALID`、`COURSE_NOT_FOUND`、`COURSE_CLASS_SECTION_NOT_FOUND`、`COURSE_CLASS_SECTION_NOT_JOINABLE`、`COURSE_SEMESTER_ARCHIVED`、`ENROLLMENT_ALREADY_ACTIVE`、`ENROLLMENT_SEMESTER_CONFLICT`、`USER_IDENTITY_CONFLICT`。
- 运动/记录：`SESSION_ALREADY_ACTIVE`、`SESSION_ALREADY_COMPLETED`、`CONFLICT_VERSION_MISMATCH`、`SESSION_DURATION_CAP_REACHED`、`COURSE_CHECKIN_WINDOW_CLOSED`、`SESSION_OUTSIDE_TIME_WINDOW`、`EXERCISE_RECORD_RESUBMISSION_NOT_ALLOWED`、`EXERCISE_RECORD_ALREADY_EXISTS_FOR_SESSION`、`COURSE_DEADLINE_PASSED`、`ENROLLMENT_NOT_ACTIVE`、`EXERCISE_RECORD_MEDIA_INCOMPLETE`。
- 媒体：`MEDIA_NOT_AVAILABLE`、`MEDIA_PROCESSING_INCOMPLETE`、`MEDIA_VERIFICATION_INCOMPLETE`、`MEDIA_STORAGE_ACCESS_DENIED`、`MEDIA_STORAGE_AUTHORIZATION_EXPIRED`、`MEDIA_STORAGE_SIGNATURE_REJECTED`、`MEDIA_STORAGE_UPLOAD_FAILED`。
- 账号注销：`ACCOUNT_DELETION_ACTIVE_SESSION`、`ACCOUNT_DELETION_PENDING_REVIEW`、`ACCOUNT_DELETION_REAUTH_REQUIRED`、`ACCOUNT_DELETION_CHALLENGE_EXPIRED`、`ACCOUNT_DELETION_VERIFICATION_CODE_INVALID`。

建议：新 Contract 确认后替换错误模型和映射表；不得把以上旧 code 当作新 Contract 的必选集合。
