## 用途和隔离

现有 startG1Runtime 仅接受 NODE_ENV=development；示例配置仍默认 P7_PLAN_CATALOG_MODE=unavailable，不自带合成文件。run-g1 创建独立内部 Docker 网络、随机测试数据库密码及临时库；运行进程测试的目录/密钥只在容器临时目录生成并删除。测试发布产生的课程、密钥、目录和 publication token 不导入正式数据库。没有正式发布环境验收或部署授权；名称或标签本身也不构成生产隔离证明。

权威来源缺失、不完整、SHA/组织/学期版本/规则不一致时，继续明确不可用，不能以最近成功缓存或合成目录生成有效的正式发布凭据。正式数据到位后的实际验收仍待执行。

## 课程日程与教师 SLA 分开

Course 发布目录需要版本化完整计划集合：分类、具体可用时间段、规则/学期绑定，以及发布所需的可达性和截止约束。
