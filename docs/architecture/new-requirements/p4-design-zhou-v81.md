**A-03。** 发布前可完成性要有可复核见证，不能仅验证 `目标合计=1200`：

1. 校验允许日程位于合法学期范围，常规截止、七天收尾和结算计划顺序符合正文；使用服务器上海日期/周。
2. 以允许日程产生潜在真实会话时段和业务日期容量，只有存在达到门槛的 ACTIVE 时段才有可计容量，单次至多 60；不能把不足门槛的短窗口当 60 分钟。
3. 将每日期的可实现类别候选与日/周约束一起做精确可达性计算，认证输入为 0；同时验证所选会话时段不重叠、未超出允许日程。输出达到两类目标的会话日程见证，才有充分的发布依据。
4. `60 × Σ每周 min(周上限, 可用日期数)` 只能作总容量必要条件，不是充分条件；还须校验分类容量、可用时段和学期范围。全员可完成性不能依赖尚未指定对象的补练或将来可能认证；已公布收尾期的个别补练不当作全员既得容量。

```python
from collections import Counter, defaultdict
from datetime import timedelta

def eligible_minutes(active_seconds, threshold):
    whole = active_seconds // 60
    return 0 if whole < threshold else min(whole, 60)

def business_week(day):
    return day - timedelta(days=day.weekday())

def select_credit(candidates, targets, certification, threshold, weekly_limit,
                  previous_ids=()):
    # candidates 只接收 P4-H「B-有效候选结果」；此处不判定审核有效性。
    # started_at 是可比较的服务端 instant，day 是固化的上海业务日期。
    assert threshold in (30, 45, 60) and weekly_limit in (2, 3, 4)
    assert len(targets) == len(certification) == 2
    assert all(isinstance(t, int) and t >= 0 for t in targets)
    assert sum(targets) == 1200 and all(c >= 0 for c in certification)
    assert len({r["id"] for r in candidates}) == len(candidates)
    base = tuple(min(targets[c], certification[c]) for c in (0, 1))
    room = tuple(targets[c] - base[c] for c in (0, 1))
    rows = sorted(
        [dict(r, q=eligible_minutes(r["active_seconds"], threshold))
         for r in candidates],
        key=lambda r: (r["started_at"], r["id"]))
    positive = [r for r in rows if r["q"] > 0]
    by_id = {r["id"]: r for r in positive}
    bit = {r["id"]: 1 << (len(positive) - 1 - i)
           for i, r in enumerate(positive)}
    by_day = defaultdict(list)
    for r in positive:
        by_day[r["day"]].append(r)

    # key=(本周已选条数, 两类已分配运动分钟); value=(平局位序, 见证ID元组)
    dp = {(0, 0, 0): (0, ())}
    last_week = None

    def keep(table, key, witness):
        if key not in table or witness[0] > table[key][0]:
            table[key] = witness

    for day in sorted(by_day):
        week = business_week(day)
        if week != last_week:
            reset = {}
            for (_, x, y), witness in dp.items():
                keep(reset, (0, x, y), witness)
            dp, last_week = reset, week
        nxt = {}
        for (k, x, y), (mask, ids) in dp.items():
            keep(nxt, (k, x, y), (mask, ids))  # 当天不选
            if k == weekly_limit:
                continue
            for r in by_day[day]:            # 当天至多选一条
                amounts = [x, y]
                c = r["category"]            # 0=课程相关，1=其他
                amounts[c] = min(room[c], amounts[c] + r["q"])
                if amounts == [x, y]:
                    continue                # 实际贡献0，不占计入名额
                key = (k + 1, amounts[0], amounts[1])
                keep(nxt, key, (mask | bit[r["id"]], ids + (r["id"],)))
        dp = nxt

    (best_key, best_witness) = max(
        dp.items(), key=lambda item: (item[0][1] + item[0][2], item[1][0]))
    optimum = sum(base) + best_key[1] + best_key[2]
    chosen = best_witness[1]

    def allocate(ids):
        remaining = list(room)
        actual = {}
        for r in sorted((by_id[i] for i in ids),
                        key=lambda r: (r["started_at"], r["id"])):
            c = r["category"]
            actual[r["id"]] = min(r["q"], remaining[c])
            remaining[c] -= actual[r["id"]]
        totals = tuple(targets[c] - remaining[c] for c in (0, 1))
        return actual, totals

    # “保留原组合”按完整集合判断，不自行增加“尽量保留交集”规则。
    old = tuple(previous_ids)
    if len(set(old)) == len(old) and all(i in by_id for i in old):
        old_rows = [by_id[i] for i in old]
        unique_days = len({r["day"] for r in old_rows}) == len(old_rows)
        counts = Counter(business_week(r["day"]) for r in old_rows)
        if unique_days and all(n <= weekly_limit for n in counts.values()):
            old_actual, old_totals = allocate(old)
            if all(v > 0 for v in old_actual.values()) and sum(old_totals) == optimum:
                chosen = tuple(r["id"] for r in sorted(
                    old_rows, key=lambda r: (r["started_at"], r["id"])))
    actual, totals = allocate(chosen)
    assert sum(totals) == optimum
    return {
        "selected_ids": chosen,
        "certification_counted": base,
        "category_totals": totals,
        "total": optimum,
        "record_actual": {r["id"]: actual.get(r["id"], 0) for r in rows},
    }
```

### 2.4 正确性、平局与规模边界

**A-09。** 动态规划状态 `(k,x,y)` 完整保留本周已占名额及两类已分配运动分钟；每个日期只能不选或选择当天一条，换周只清零 k、保留两类累计。分类累计饱和到 R 后，多余分钟不影响未来可达结果。同一状态的后续选择集合相同，因此不能因为某一类当前更多就丢弃另一类别状态，也不使用每周单独求一个最高标量的贪心。〔S-A；A-06～08。〕

**A-10。** 总量优先于所有平局偏好。先求最大 F，再检查原完整组合是否仍来自当前有效候选、日/周合法、各条有实际贡献且 F 等于最优值；成立则保留原组合。原组合已非最优或不再合法时，按候选 `(开始 instant,稳定 ID)` 排序，最早出现差异的位置优先保留该记录；实现为较早候选对应较高位、1 优先于 0 的成员位序。该位序只用于同一状态或同总量比较，追加共同的未来选择不改变已有位序优先级。没有另加“最大化原组合交集”或“最少记录条数”规则。无正贡献的候选不占计入名额；其运动记录仍保存。〔S-A；总览 §11.3；A-07～08。〕

**A-11。** 单调性证明：规则、目标、认证及统计对象范围不变，新增有效候选得到集合 E'⊇E；旧最优组合仍是 E' 中的可行组合，故 `max F(E')≥max F(E)`。补证通过只扩充 E，不改变旧记录日期/周、q 或规则，所以同样成立。DP 不会因较早补证通过强制替换更优记录；保留原组合只是等总量时的偏好。纠正无效、撤销认证或成员范围变化不满足此前提，可能使结果减少，必须展示来源变更原因。每条记录的 a 不要求单调，总有效进度才是此处保证对象。〔S-A；AT-13/14。〕

**A-12。** 完备性说明：任何合法组合都可按业务日期依次作“不选/选一条”的转移；若某条转移增加 0，删掉它不会改变后续分类完成量，且只释放名额，因此跳过零贡献转移不会损失最大值。相同 `(k,x,y)` 保留位序较优的见证仍覆盖全部可能的未来结果。空候选集也有 `(0,0,0)`，结果是认证封顶量，不伪造运动。类别目标为 0 时该类记录仍保存但不计入。〔S-A；A-06～10。〕

**A-13。** 分钟整数状态上限为 `(K+1)(R_0+1)(R_1+1)`，R 总和不超过 1200，最宽类别乘积为 601×601。时间量级为 `O((D+N)·K·(R_0+1)·(R_1+1))` 的状态转移，D 为有候选日期数、N 为候选数；此量级不包含 Python 见证元组复制、大整数位序和回溯存储成本。伪代码优先可审查性，生产实现还需压缩可达状态、父指针重建和真实规模评估。不能为了性能改为未经证明的贪心；未执行性能测试，不将此参考算法宣称为已满足生产容量。〔工程分析；A-08；S-A。〕

### 2.5 P4Z.A.StatisticsProjection（唯一统计定义）

**A-14。** Record 投影保留原始 ACTIVE 秒及实际整分钟 m，并分列：可计分钟 q、实际计入分钟 a、未计入原因。`0≤a≤q≤60`；q=0 或 B 不提供该记录为有效候选时 a=0。可计量只描述时长公式潜力，不等于审核通过。显示 B 的原审核/流程状态，不能把待处理或有效未选中改写为 INVALID；无效原因由 B 提供，A 不扩展六类公开审核原因。〔S-A；S-BF；总览 §11.3/12.1/15。〕

**A-15A（解释对应的分钟范围）。** A-15的解释须区分时长公式和选择结果：`m-q`解释未达门槛或单次封顶，`q-a`解释有效候选的可计量未全部计入，两者不得混成A-17的有效未计入列。有效90分钟且q=a=60时，仅有公式未纳入30，不得说60可计分钟未计入；有效29:59时q=a=0、U=0，解释门槛即可，不能把该29分钟归因为日/周名额竞争。已取得的无效/待处理结果只引用B；B来源未知时沿A-05保持待取得一致结果，不能由A猜成某种审核状态。〔S-A/S-BF；总览§11.3/15/21；AT-09/12/14；A-04/14/15/17；本会话第二项统计确认；旧设计§5.4/5.7。〕

**A-PLAN-03。** 在有限、已确认合法的计划目录内，使用下列精确可达状态补充时间约束。状态比A-08多保存最近选中会话的结束instant；换周只清名额、不清结束instant。选项占用从开始到结束的完整会话时段，PAUSED期间也不能容纳另一会话；ACTIVE秒数只用于可计公式。不同日期并不保证互不重叠。此参考算法只需返回任一可行最优计划见证，真实记录的原组合优先仍仅由A-08定义。〔S-R/S-A；AT-11/22；旧设计§5.4；A-04/08；ISS-013。设计伪代码，非产品实现。〕

```python
from collections import defaultdict
from zoneinfo import ZoneInfo
from datetime import timedelta

def plan_catalog_max(options, targets, threshold, weekly_limit):
    # 前提：课程Owner已确认这些计划选项合法；不是B的真实有效记录。
    # 每项含option_id/start/end/active_seconds/category；不写Session/Record。
    assert threshold in (30, 45, 60) and weekly_limit in (2, 3, 4)
    assert len(targets) == 2 and sum(targets) == 1200
    assert all(isinstance(t, int) and t >= 0 for t in targets)
    assert len({o["option_id"] for o in options}) == len(options)
    assert all(o["category"] in (0, 1) for o in options)
    assert all(o["start"].utcoffset() is not None and o["end"].utcoffset() is not None for o in options)
    shanghai = ZoneInfo("Asia/Shanghai")
    groups = defaultdict(list)
    for option in sorted(options, key=lambda o: (o["start"], o["option_id"])):
        assert option["end"] > option["start"]
        assert 0 <= option["active_seconds"] <= (option["end"]-option["start"]).total_seconds()
        day = option["start"].astimezone(shanghai).date()
        groups[day].append(option)
    # key: 本周条数、两类完成量、最近已选会话的结束instant
    dp = {(0, 0, 0, None): ()}
    last_week = None
    for day in sorted(groups):
        week = day-timedelta(days=day.weekday())
        if week != last_week:
            reset = {}
            for (_, x, y, end), ids in dp.items():
                reset.setdefault((0, x, y, end), ids)
            dp, last_week = reset, week  # end不能随换周清空
        nxt = dict(dp)                  # 当天不选
        for (k, x, y, end), ids in dp.items():
            if k == weekly_limit:
                continue
            for o in groups[day]:
                if end is not None and o["start"] < end:
                    continue           # PAUSED也占据该会话的完整时段
                whole = o["active_seconds"]//60
                q = 0 if whole < threshold else min(whole, 60)
                amounts = [x, y]
                c = o["category"]
                amounts[c] = min(targets[c], amounts[c]+q)
                if amounts == [x, y]:
                    continue
                key = (k+1, amounts[0], amounts[1], o["end"])
                nxt.setdefault(key, ids+(o["option_id"],))
        dp = nxt
    state, ids = max(dp.items(), key=lambda item: item[0][1]+item[0][2])
    return {"catalog_max": state[1]+state[2],
            "category_totals": (state[1], state[2]), "witness": ids}
```
