# BNBU Sports Web 学生端隐私政策

版本：2.1

更新日期：2026 年 7 月 28 日

生效日期：2026 年 7 月 28 日

本政策适用于 BNBU Sports Web 学生端及其课程、运动打卡、运动时长、成绩与学生服务功能，说明我们如何处理个人信息以及您如何行使相关权利。

## 一、基本原则

我们仅为明确、合理且必要的教学管理、安全保障和服务支持目的处理个人信息，并采取与风险相适应的安全措施。请在登录或使用服务前阅读本政策。

## 二、我们处理的信息

为提供账号和教学服务，我们可能处理学号、姓名、院系、年级、班级、性别、学校邮箱、账号状态、课程关系、运动会话、打卡记录、成绩、申请材料、审核结果以及必要的安全日志。

学生账号统一通过学校邮箱验证码认证。Web 学生端不提供手机号或短信验证码登录，不保存明文验证码、密码或完整访问令牌到普通日志。

只有在您主动使用运动打卡、免修申请或反馈等功能时，我们才处理您提交的照片、视频和文件。

## 三、浏览器权限

只有在您主动扫码、拍照或录像时，Web 学生端才请求相机或麦克风权限。拒绝相机权限后仍可手动输入教师提供的邀请码。

Web 学生端不申请前台或后台定位权限，不主动采集经纬度，不创建运动轨迹，也不读取附近 Wi-Fi、蓝牙设备或定位传感器信息。

## 四、运动凭证

运动凭证页面仅提供现场采集入口，不主动扫描相册或读取无关文件。部分桌面或不支持现场采集的浏览器可能显示系统文件选择器；应用仅处理您明确返回的文件，并由 Backend 对采集来源和媒体真实性作最终裁决。

照片会在浏览器可解码时重编码为 JPEG，以移除原始 EXIF 和位置元数据。视频最长 15 秒且必须包含真实视频轨和音轨。Backend 会校验实际容器、MIME、文件大小、SHA-256、真实时长和媒体轨道。

如果文件本身包含可识别的 GPS、EXIF 位置或视频容器位置元数据，Backend 会拒绝该文件并要求重新拍摄，不会把坐标作为运动业务事实保存。

未提交的媒体草稿只保留在当前浏览器会话或本地存储能力允许的范围内；主动放弃或成功提交后会清理对应草稿。已提交材料按照学校教学记录和适用法律规定保存。

## 五、课程、打卡和申请处理

课程邀请、入课、运动会话、打卡记录、运动说明、凭证、免修申请和成绩用于完成教学流程、防止重复提交、处理并发冲突并供获授权的教师或管理员审核。Backend 是身份、权限、运动状态、有效时长、成绩和媒体生命周期的最终裁决者。

## 六、技术信息与日志

为保障连接、安全和故障排查，请求可能包含浏览器及操作系统版本、语言、网络状态、时区、IP 地址、请求路径、HTTP 状态、稳定错误码和 requestId。普通日志不得记录密码、验证码、完整 Token、数据库连接串、storageKey 或签名 URL。

当前 Web 学生端未集成广告、行为画像、自动崩溃上报或第三方定位 SDK，也不使用个人信息进行广告推荐。

## 七、使用、共享与披露

我们仅为提供、保护、维护教学服务，履行法定义务及处理争议使用个人信息。我们不出售个人信息。只有在必要且合法时，才向获授权的学校人员或受约束的服务提供者提供相关信息；法律另有要求的除外。

## 八、存储与安全

个人信息按照账号、教学、审计和法律目的所需期限保存。我们采取访问控制、传输加密、安全存储、日志审计和事件响应措施。任何传输或存储方式均无法保证绝对安全；发生依法需要通知的事件时，我们将按规定处理。

## 九、您的权利

在适用法律范围内，您可以请求访问、更正、删除、解释相关个人信息，撤回基于同意的处理，或请求账号协助。撤回不影响此前基于有效依据完成的处理，但可能导致依赖相应信息的功能不可用。

学生端没有手机号、短信验证码或自助账户恢复入口。如邮箱无法使用，请通过学校官方支持渠道联系体育教学管理部门或账号管理员核验身份。

## 十、未成年人和政策更新

服务主要面向高校学生、教师和管理员。未满 18 周岁的用户应在监护人指导下阅读；涉及未满 14 周岁儿童个人信息时，将依法取得监护人授权。服务或法律要求发生重大变化时，我们会更新政策并进行显著提示。

## 十一、联系我们

如对本政策或个人信息处理有疑问、请求或投诉，请通过学校官方支持渠道联系北京师范大学珠海校区体育教学管理部门。我们将按照适用法律和学校流程处理。

## 十二、审阅提示

本政策文本已按当前 Web 学生端的技术行为整理；对外正式发布前仍需由学校完成法律与制度审阅。
